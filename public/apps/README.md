# App asset convention

Create one folder per app slug. The website intentionally renders branded placeholders until these optional files are added:

- `icon.png`
- `hero.webp`
- `screenshot-1.webp`
- `screenshot-2.webp`
- `screenshot-3.webp`

Only use artwork and screenshots you own or are licensed to distribute. Add accurate alt text when wiring real screenshots into `src/components/ScreenshotGallery.tsx`.
